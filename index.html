A self-programmed ESP32 micro-quadcopter — every wire and every line of flight-control code done deliberately, one stage at a time.

See the build log Full spec
FRAME + MOTORS

Q100 frame, 8520 motors

100mm motor-to-motor wheelbase, injection-molded plastic X-frame. The motors stay seated in the arm tubes — everything else explodes away from this anchor.

POWER

1S LiPo, 400mAh

Strapped underneath the center plate, wired up through the power board.

POWER BOARD

Perfboard + IRLZ44N MOSFETs

Hand-soldered switching for all four motors, driven directly from the ESP32's PWM outputs.

IMU

MPU6050 (GY-521)

VCC → 3.3V, GND → GND, SCL → GPIO22, SDA → GPIO21. Raw accelerometer and gyro data read over I2C.

FLIGHT CONTROLLER

ESP32 DevKit V1

Runs the complementary filter, PID loop, motor mixing, and the WiFi control link — all hand-written.

PROPS

65mm two-blade props

Mirrored CW/CCW pairs — front-left and rear-right spin one way, front-right and rear-left the other.

CONCEPT

Why hand-built, not kit-assembled.

AIA-1X isn't a kit build. Every part was sourced individually and every line of flight-control firmware is written from scratch, stage by stage. The goal isn't the fastest path to a flying quadcopter — it's understanding the system well enough to debug it blind before ever trusting it to lift off. This is phase one of a longer roadmap toward an autonomous delivery drone, and the discipline built here carries forward into every phase after it.

    Closed-loop stabilization, converting attitude error into correction output.

    queued
  4. 04

    Motor mixing / PWM

    Translating PID output into individual motor throttle signals.

    queued
  5. 05

    WiFi phone control

    Wireless control link from a phone interface to the ESP32.

    queued
  6. 06

    Bench testing, props off

    Full-system dry run confirming motor response and control logic before any lift.

    queued
  7. 07

    PID tuning

    Live tuning pass once airborne. Backflip capability is deferred to AIA-2.

    queued
