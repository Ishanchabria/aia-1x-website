AIA-1X

Built by hand. Coded from scratch.

A self-programmed ESP32 micro-quadcopter — every wire and every line of flight-control code done deliberately, one stage at a time.

FRAME

Q100 brushed frame

100mm wheelbase, ~12g, built for 8520 coreless motors. Carries an FPV mount reserved for AIA-2.

MOTORS

8520 coreless motors

Driven through IRLZ44N MOSFETs, switched directly from the ESP32's PWM outputs.

IMU

MPU6050 (GY-521)

VCC → 3.3V, GND → GND, SCL → GPIO22, SDA → GPIO21. Raw accelerometer and gyro data read over I2C.

FLIGHT CONTROLLER

ESP32 DevKit V1

Runs the complementary filter, PID loop, motor mixing, and the WiFi control link — all hand-written.

POWER

1S LiPo, 350–450mAh

Witty Fox pack. Exact capacity still being finalized on stock availability.

CONCEPT

Why hand-built, not kit-assembled.

AIA-1X isn't a kit build. Every part was sourced individually and every line of flight-control firmware is written from scratch, stage by stage. The goal isn't the fastest path to a flying quadcopter — it's understanding the system well enough to debug it blind before ever trusting it to lift off. This is phase one of a longer roadmap toward an autonomous delivery drone, and the discipline built here carries forward into every phase after it.
